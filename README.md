# 📈 Stock Market Portfolio Dashboard (Frontend)

A **single-page web application** for tracking live-style market data, managing a virtual portfolio, and maintaining a watchlist.  
Built with **vanilla HTML, CSS, and JavaScript** using **in-memory sample data** (no backend or database required).  

---

## ✨ Features

- 📰 **Market Overview Cards** for major indices:  
  **S&P 500**, **NASDAQ**, **Dow Jones**, **Russell 2000**
- 📊 **Sample stock universe** with:  
  _price, change %, volume, 52-week range, sector, etc._
- 🔐 **User Authentication Flow**  
  (Register, Login, Logout with password validation)
- 💼 **Virtual Portfolio**
  - ➕ Add holdings (symbol, shares, price)
  - 📈 View current value & unrealized P/L
  - 💵 Sell existing holdings
- 👀 **Watchlist**
  - ➕ Add/Remove stocks
  - ⚡ Quick view of prices & changes
- 🚀 **Market Movers & Featured Stocks** section
- 📰 **News-style cards** with sample headlines
- 🎨 **Responsive UI** with **light/dark theme** using CSS custom properties

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript  
- **Styling:** Custom design system using CSS variables  
- **State Management:** In-memory JavaScript objects  
- **Runtime:** No build tools — runs directly in browser  

---

## 🚀 Getting Started

### 🔧 Prerequisites

- ✔ Any modern browser: Chrome, Edge, Firefox, Safari  
- ✔ Optional static server:  
  - VS Code Live Server  
  - `npx serve`  
  - `python -m http.server`

---

## 📥 Installation

1. Clone or download this repository.
2. Make sure the following files are in the same folder:
   - `index.html`
   - `style.css`
   - `app.js`

---

## ▶️ Running the App

1. Double-click **`index.html`** or open it manually in a browser.
2. All interactions work instantly.  
   ⚠️ Some browsers may restrict features when opened from the filesystem.
